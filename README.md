# Pocket Realms — prototype 0.0.1

A small Godot 4 3D prototype for a top-down fantasy action MMORPG concept.

## Included
- Stylized placeholder terrain, houses, trees, and player
- Keyboard (WASD/arrows) and mobile left-side touch movement
- Melee attack (spacebar / touch button)
- Three wolves that chase and damage the player
- HP, respawn, and kill counter

## Run
Open `project.godot` with **Godot 4.3 or newer** and press F6/F5 to run the main scene.

## Web/Android builds
The repository contains **source**, not a ready-made browser or APK build. Export templates and an export preset are needed for publishing. For the web build use Godot's Compatibility renderer and configure GitHub Pages deployment separately.
